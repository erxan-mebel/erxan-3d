# Промпт · Монтаж (толық нұсқа)

Видеоларды осы чатқа салып, мына үлгіні толтырып жіберіңіз:

```
Видео: [не туралы, кім үшін — мысалы: СТО жарнамасы / кухня тапсырысы]
Мақсат: [клиент жазсын / танымал болу / сенім]
Ұзақтығы: [30–40 с]
Мәтін: [видеода не айтылады немесе экранда не жазылсын]
Деректер: [аты, телефон, мекенжай, қызметтер, баға — соңғы кадрға]
Стиль: СТО HyperFrames нұсқасындай (қозғалатын белгілер, карточкалар)
Музыка: [энергиялы / домбыра / музыкасыз — өзім Instagram-да қосамын]
Алдымен кадрларын көрсет, сосын шығар.
```

Қысқа нұсқасы:
```
Осы видеолардан HyperFrames стилінде 30 секундтық Reels жаса.
Аты: ..., телефон: ..., мекенжай: ..., қызметтер: ....
Музыкасыз және энергиялы музыкамен екі нұсқа бер.
```
