# Референс №1 — «Твой монтажёр больше не нужен» (65 с) — талдау

## Құрылымы
| Уақыт | Не көрінеді |
|---|---|
| 0–3 с | **Hook**: бет жақын план, микрофон, қараңғы фон + күшті сөйлем субтитрмен |
| 3–9 с | Сөйлеу + экранға шығатын элемент (іздеу жолағы, прогресс-бар) |
| 9–35 с | **Анимация бөлімі**: ақ фон, пиксель қаріп тақырып («ЗА 3 ШАГА»), 1-2-3 қадам белгісі, **бетінің фотосы қойылған мультяшный адамша**, браузер/терминал терезелері, мәтін өзі жазылып жатыр |
| 35–48 с | Бетке қайта оралады, тағы анимация |
| 48–57 с | Анимация: нәтиже (дайын видео, монтаж таймлайны түрленеді) |
| 57–65 с | **CTA**: «директке МОНТАЖ деп жаз» — кілт сөз үлкен сары әріппен |

## Тәсілдері
- Бет (A-roll) мен анимация (B-roll) кезектесіп отырады — көрермен жалықпайды.
- Анимацияда кейіпкер — автордың бетінің фотосы + сызба денесі.
- Ақ фон, қара пиксель қаріп, 2–3 түсті акцент (көк, қызыл).
- Субтитр кішкентай, ортада; кілт сөздер ерекшеленеді.
- Соңында кілт сөзбен директке шақыру (комментарий/директ көбейеді).

## Бізде қалай жасаймыз
- Сөйлейтін бөлімді сіз түсіресіз (сценарий бойынша, 40–60 с).
- Анимация бөлімдерін мен HTML/HyperFrames-пен жасаймын: сіздің бетіңіз + сызба денесі, Erxan Mebel түстері (мыс, қара, ақ).
- Субтитр Whisper, монтаж FFmpeg.
