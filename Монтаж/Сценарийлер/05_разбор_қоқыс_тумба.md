# Reels — разбор «Дөңгелекті қоқыс тумбасы» (референс №2 форматында, ~22 с)

Формат: біреудің видеосы фонда + сіздің бетіңіз дөңгелек ішінде (сол жақ төменде) + қазақша субтитр.
Мәтін фондағы кадрларға сәйкес келеді — әр жолды көрсетілген уақытқа шамалап айтыңыз.

| Уақыт | Фонда не көрінеді | Сіз айтасыз |
|---|---|---|
| 0–3 с | Тумба үстелге қарай жүріп келеді | «Американдықтар қоқысқа енді жүгірмейтін етіп ойлап тапты.» |
| 3–6 с | Үстелдегі қиқымды сыпырады | «Тумба өзі үстелге келеді — қиқымды тура ішіне сыпырасыз.» |
| 6–9 с | Тарелкадағы қалдықты салады | «Тарелкадағы қалдық та сонда — еденге бір түйір түспейді.» |
| 9–11 с | Террасаға апарады | «Үстелге де, террасаға да апара бересіз.» |
| 11–14 с | Орнына итеріп қояды | «Ал орнына итеріп қойсаңыз — кәдімгі тумба. Қоқыс көрінбейді.» |
| 15–18 с | Астын тазалайды | «Ең кереметі — астын бес секундта тазалайсыз.» |
| 18–22 с | Тумба жабық тұр | «Мен мебельшімін — мұндай тумбаны біз де жасаймыз. Керек болса, комментарийге "ТУМБА" деп жазыңыз.» |

## Түсіру
- Алдыңғы камерамен, тік, 1080p 30 к/с; бетіңіз кадрдың ортасында, иықтан жоғары.
- Тыныш жерде, жарық бетке түссін (терезеге қарап тұрыңыз).
- Бір дублмен 25–30 с сөйлеңіз; қате кетсе, сөйлемді қайта айта беріңіз.
