# 3D — Erxan Mebel жиһаз сызбасы

Корпустық жиһазды (асүй, шкаф) клиенттің алдында тез сызып, 3D-да көрсетуге арналған браузер бағдарламасы.
Телефонда, планшетте және компьютерде ашылады. Бағдарламаны жинаудың (build) қажеті жоқ.

## Іске қосу

```bash
cd 3D
python3 -m http.server 8765
# браузерде: http://localhost:8765
```

`index.html` файлын тікелей ашу (`file://`) жұмыс істемейді, себебі ES модульдер үшін сервер керек.

## Құрылымы

| Файл | Не істейді |
|---|---|
| `index.html` | Интерфейс (жоғарғы панель, «Бөлме / Шкафтар / Баптау» бөлімдері), стильдер |
| `src/main.js` | 3D сахна, камера, шкафтарды сүйреу және қабырғаға жабыстыру, «артқа қайтару», сақтау |
| `src/room.js` | Бөлме: еден, қабырғалар, өлшем сызықтары |
| `src/cabinet.js` | Дайын корпустар каталогы және оларды ЛДСП панельдерінен құру |
| `vendor/` | three.js 0.170.0 (MIT лицензиясы, `vendor/THREE-LICENSE`) |

Бірлік — миллиметр. Жоба браузердің `localStorage` жадында автоматты сақталады.

## Жоспар

1. ✅ Бөлме, 3D көрініс, өлшемдер, дайын корпустар, сүйреу және қабырғаға жабыстыру
2. Есіктер мен тартпалардың ашылып-жабылуы, материалдар (ЛДСП, МДФ, акрил, текстуралар)
3. Баға есептеу және деталдар тізімі (кесуге)
4. SketchUp сияқты жеке деталь сызу
5. Бұрыштық шкафтар, терезе мен есік, техника
6. AR: телефон камерасы арқылы көрсету
7. Клиенттердің жобаларын сақтау және экспорттау
