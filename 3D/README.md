# 3D — Erxan Mebel жиһаз сызбасы

Корпустық жиһазды (асүй, шкаф) клиенттің алдында тез сызып, 3D-да көрсетуге арналған браузер бағдарламасы.
Телефонда, планшетте және компьютерде ашылады. Бағдарламаны жинаудың (build) қажеті жоқ.

## Іске қосу

```bash
cd 3D
python3 -m http.server 8765
# браузерде: http://localhost:8765
```

`index.html` файлын тікелей ашу (`file://`) жұмыс істемейді, себебі ES модульдер үшін сервер керек.

## Құрылымы

| Файл | Не істейді |
|---|---|
| `index.html` | Интерфейс (жоғарғы панель, «Бөлме / Шкафтар / Баптау» бөлімдері), стильдер |
| `src/main.js` | 3D сахна, камера, шкафтарды сүйреу және қабырғаға жабыстыру, «артқа қайтару», сақтау |
| `src/room.js` | Бөлме: еден, қабырғалар, өлшем сызықтары |
| `src/cabinet.js` | Каталог (төменгі, үстіңгі, бұрыштық, биік шкафтар, техника) және олардың 3D модельдері |
| `src/facade.js` | Есік түстері, ағаш текстурасы, өрнектер (рамка, шейкер, классика, ою, әйнек, өз суреті) |
| `build.mjs` | Бір файлдық нұсқа: `node build.mjs` → `dist/erxan3d.html` |
| `vendor/` | three.js 0.170.0 (MIT лицензиясы, `vendor/THREE-LICENSE`) |

Бірлік — миллиметр. Жоба браузердің `localStorage` жадында автоматты сақталады.

## Жоспар

1. ✅ Бөлме, 3D көрініс, өлшемдер, дайын корпустар, сүйреу және қабырғаға жабыстыру
2. ✅ Есік түстері, ағаш, жылтыр/күңгірт, өрнектер (фрезеровка), қазақ оюы, әйнек, өз суреті
3. ✅ Бұрыштық шкафтар, жуғыш, плита + духовка, пенал (духовка + микро), техника: тоңазытқыш, плита, сорғыш, ыдыс жуғыш, микротолқынды (2 түрі), кір жуғыш, теледидар
4. Есіктер мен тартпалардың ашылып-жабылуы
5. Баға есептеу және деталдар тізімі (кесуге)
6. SketchUp сияқты жеке деталь сызу
7. Терезе мен есік (бөлмеде)
8. AR: телефон камерасы арқылы көрсету
9. Клиенттердің жобаларын сақтау және экспорттау
