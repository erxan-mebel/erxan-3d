# Бәсекелестер трекері

Бәсекелес мебельшілердің Instagram-дағы соңғы 50 постын тексеріп, **әдеттегіден 3 есе көп**
лайк/пікір жинағандарын «🔥 атып кетті» деп белгілейді. Нәтиже: `report.html`, `report.md`.

## Іске қосу
1. `competitors.txt` — бәсекелестердің аккаунттарын жазыңыз.
2. Instagram Graph API баптауы (бір рет): профессиональный аккаунт → Facebook беті → Meta App → токен.
3. `IG_USER_ID=<сіздің аккаунт id> python3 Бәсекелестер/tracker.py`
   Сынап көру: `python3 Бәсекелестер/tracker.py --demo`

Шектеулер: Instagram бөтен аккаунттардың қаралым санын бермейді (лайк, пікір ғана);
тек бизнес/автор аккаунттары; лайкты жасырған аккаунттар пікір бойынша бағаланады.
